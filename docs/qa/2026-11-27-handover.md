### FIH-03 guest library empty after landing, then "Continue as guest" (not reproduced, no change)
Read the code path. `enterGuestMode()` only sets `localStorage["fihrist:guest-mode:v1"]="1"` and navigates to `/library`. Guest data is one IndexedDB record (`fihrist-private-guest-v1` / `workspace` / key `library`), read and written by fixed name. There is no guest id. Nothing in the client clears, deletes or recreates that store (`leaveGuestMode()` removes only the flag; no `deleteDatabase`, `clear()` or version bump). So code cannot cause the reset.
Likely environmental causes to verify on production: a private window or storage-partitioned/ephemeral browser profile (flag and IndexedDB behave differently between reload and a new navigation), a different origin or host (e.g. preview vs `fihristy.vercel.app`) between the two visits, or the browser evicting IndexedDB. Not verified live; no fake-indexeddb in the repo and no new deps allowed, so no automated repro.
