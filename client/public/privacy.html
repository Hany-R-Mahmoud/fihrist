Privacy Policy

Fihrist is a bookmark-organizing application. This page describes its current public website and how the optional cloud and Google Sign-In features are intended to handle information as they become available.

Current availability

The public Fihrist website is informational while authenticated cloud library access is being prepared. Signing in and cloud bookmark storage are not yet enabled on this website. Existing locally stored SQLite bookmarks are not automatically uploaded or published by visiting this site.

Information processed when cloud features are enabled

With your permission, Google Sign-In will provide basic identity details such as your name, email address, and optional profile photo. Fihrist does not request access to Gmail, Google Drive, or your Google contacts for basic sign-in. Fihrist will store the bookmarks, URLs, notes, collections, tags and associated metadata that you choose to save or import.

How your information is used

  • Authenticate your account and keep your private library separate from other users.
  • Save, organize, search and export bookmarks you choose to add.
  • Retrieve public webpage metadata and optionally check saved-link health.
  • Run optional AI features only when configured; webpage information may be sent to the selected external AI provider to generate suggestions.

Infrastructure and service providers

The public site is hosted using Vercel, which may process routine network and diagnostic logs. Cloud data and managed account authentication are being prepared using Neon PostgreSQL and Neon Auth. Google processes Google Sign-In under its own privacy terms. Fihrist does not sell your bookmarks or Google profile details.

Security and sharing

Bookmarks are intended to be private to your signed-in account. Private library data is not intentionally displayed on the public landing page. Any future cloud import from a local SQLite database will require an explicit action and will preserve your original local data during migration.

Retention and deletion

You control when you add or export bookmarks. Once cloud access is enabled, account/library deletion and export options will be documented before launch. Until then, no visitor-facing cloud library data is collected by this website.

Contact and updates

For questions about this policy or requests concerning Fihrist data, contact the maintainer through Fihrist's GitHub Issues. The policy will be updated when cloud features go live, with material changes reflected on this page.
